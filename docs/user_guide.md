# User guide / demo script
1. Open Home and read the disclaimer. 2. Diabetes Risk: fill every required field (leave optional ones blank if unknown) and press Predict. 3. Read the score, the limits and the guidance. 4. Ask the assistant "What does my score mean?". 5. Try voice only if set up. 6. Trusted Contact: save a number, tick the confirmation, and **do not** press the dialer unless you want to call. 7. Model Performance: explain the confusion matrix (false negatives vs false positives).
Sample inputs should come from the dataset's ranges; mark any demo data as synthetic.
